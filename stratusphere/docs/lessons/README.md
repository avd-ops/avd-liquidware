# Lessons

Lessons from real runs now live in the knowledge base: on the topic page they belong to under
[docs/knowledge/](https://github.com/nickprignano/liquidware-ninja/blob/main/docs/knowledge/README.md), and errors with a known cause in
[known-errors.yaml](https://github.com/nickprignano/liquidware-ninja/blob/main/docs/knowledge/troubleshooting/known-errors.yaml). Each lesson still
adds a guard (a Pester test or a preflight check), per
[decision 0007](https://github.com/nickprignano/liquidware-ninja/blob/main/docs/knowledge/decisions/0007-real-runs-are-the-source-of-truth.md).
